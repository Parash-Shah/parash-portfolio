# Parash Shah | Engineering Portfolio

An interactive engineering portfolio focused on distributed systems, cloud infrastructure, security engineering, reliability, and AI infrastructure.

## Why this portfolio exists

This is designed as an engineering product rather than a static resume site. Every project will become a case study that explains:

1. What problem does this solve?
2. Why does the problem matter?
3. How does the architecture solve it?
4. What happens when something fails?
5. How do we know it works?

## Current stack

- Next.js 16
- React 19
- TypeScript
- CSS-first animation and visual system
- Vercel-ready deployment

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
